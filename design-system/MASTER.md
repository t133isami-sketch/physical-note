# Physical Note デザインの土台

配布ページ（`start/index.html`）を見本にした、見た目と動きの決まりごとです。
新しいページを作るときは、AIに「`start/index.html` と同じ雰囲気で、このMASTER.mdに沿って作って」と頼みます。

## 雰囲気
- Appleの製品ページが見本。名前 → ひとこと → ボタン → 製品の画面、の順に大きく見せる。
- 白（ダークでは黒）と薄い灰色の背景を交互に。色を使うのはアイコンの紫とボタンの青だけ。
- AIっぽく見える飾りは使わない：紫〜青のグラデーション、ぼかした光、キラキラ、絵文字。
- 名前は英語で「Physical Note」と書く。

## 文章
- 配布ページなので、やることだけを短く書く。キャッチコピー風の言い回し（「〜を、〜に。」「静かに続けられる。」など）は使わない。
- 1文に1つのこと。「できます」「押します」のように、具体的な動作で書く。

## 色（`:root` の変数を使い、色コードを直接書かない）
| 役割 | 変数 | ライト | ダーク |
|---|---|---|---|
| 文字 | `--ink` | #1d1d1f | #f5f5f7 |
| 説明文 | `--sub` | #6e6e73 | #a1a1a6 |
| 注記 | `--faint` | #707075 | #86868b |
| 背景 | `--bg` / `--alt` | #fff / #f5f5f7 | #000 / #161617 |
| アイコンの紫 | `--p2` | #6a4c9c | #b9a3e3 |
| ボタン | `--blue` | #0071e3 | 同じ |

- 文字と背景のコントラストは 4.5:1 以上（注記の灰色もこれを守るために #707075 にした）。

## 文字
- システムフォント（SF Pro／ヒラギノ／Noto Sans JP など）。本文 17px、行間 1.6。
- 見出しはセミボールド（600）、字間を少し詰める（-0.025em 前後）。大きさは `clamp()` で画面幅に合わせる。
- 日本語の改行位置は `<span class="nb">` で区切って、変なところで折れないようにする。

## 形
- カードの角丸は 24px、ボタンは丸（980px）。
- ボタンや押せるものは高さ 44px 前後を目安に、指で押しやすく。
- アイコンは SVG の線画。絵文字はアイコン代わりに使わない。

## 動き
- 動きはAppleと同じくらい控えめに。要素が画面に入ったら、下から少しだけ浮き上がる（`.rv`）。並んでいるものは 90ms ずつずらす。
- イージングは `--ease-out`（cubic-bezier(.16,1,.3,1)）、0.8秒。
- 「動きを減らす」設定の人には動きをすべて止める（`prefers-reduced-motion`）。
- キーボードで操作したときは、青い枠でどこにいるか分かるようにする（`:focus-visible`）。

## 仕上げのチェック
- [ ] 375px（スマホ）と 1280px（PC）で横にはみ出さない
- [ ] ライトとダークの両方で読める
- [ ] 押せるものすべてにホバーとフォーカスの見た目がある
- [ ] 動きを減らす設定で、全部が最初から見えている
