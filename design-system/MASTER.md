# フィジカルノート デザインの土台

配布ページ（`start/index.html`）を見本にした、見た目と動きの決まりごとです。
新しいページを作るときは、AIに「`start/index.html` と同じ雰囲気で、このMASTER.mdに沿って作って」と頼みます。

## 雰囲気
- Apple風のミニマル。白（ダークでは黒）の広い余白、大きな見出し、中央ぞろえ。
- ブランド色は紫。目立たせたいボタンだけ青。
- 飾りは少なく。光のにじみ（ヒーローのうしろ）と、ふわっと出る動きだけ。

## 色（`:root` の変数を使い、色コードを直接書かない）
| 役割 | 変数 | ライト | ダーク |
|---|---|---|---|
| 文字 | `--ink` | #1d1d1f | #f5f5f7 |
| 説明文 | `--sub` | #6e6e73 | #a1a1a6 |
| 注記 | `--faint` | #707075 | #86868b |
| 背景 | `--bg` / `--alt` | #fff / #f5f5f7 | #000 / #161617 |
| ブランド紫 | `--p` / `--p2` / `--pl` | #4b2e83 / #6a4c9c / #efe8fa | — / #b9a3e3 / #2a2140 |
| ボタン | `--blue` | #0071e3 | 同じ |
| 光のにじみ | `--g1` `--g2` `--g3` | 薄紫・水色・薄桃 | 濃い同系色 |

- 文字と背景のコントラストは 4.5:1 以上（注記の灰色もこれを守るために #707075 にした）。

## 文字
- システムフォント（ヒラギノ／Noto Sans JP など）。本文 17px、行間 1.6。
- 見出しは太字、字間を少し詰める（-0.025em 前後）。大きさは `clamp()` で画面幅に合わせる。
- 日本語の改行位置は `<span class="nb">` で区切って、変なところで折れないようにする。

## 形
- カードやタイルの角丸は 28px、ボタンは丸（980px）。
- ボタンや押せるものは高さ 44px 前後を目安に、指で押しやすく。
- アイコンは SVG の線画。絵文字はアイコン代わりに使わない。

## 動き
- 開いた瞬間：見出し → 説明 → ボタン → スマホ画像の順に、少しずつずらしてふわっと出す（`.up` と `--i`）。
- スクロール：要素が画面に入ったら下からふわっと出す（`.rv`）。並んでいるものは 90ms ずつずらす。
- イージングは `--ease-out`（cubic-bezier(.16,1,.3,1)）。出てくる動きは 0.9〜1.2秒、ホバーは 0.25秒。
- 「動きを減らす」設定の人には動きをすべて止める（`prefers-reduced-motion`）。
- キーボードで操作したときは、青い枠でどこにいるか分かるようにする（`:focus-visible`）。
