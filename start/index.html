はじめかた

パソコンで10分ほど。お金はかかりません。
必要なのは Google アカウントだけです。

  1. 1

    記録用のシートをコピーする

    まだ何も書いていない記録シートを、あなたのGoogleドライブにコピーします。中身は見出しだけで、だれの記録も入っていません。

    シートをコピーする

    「コピーを作成」の画面が開きます。名前はそのままで大丈夫です。

  2. 2

    読み取り用のコードを貼る

    コピーしたシートで、アプリがあなたの記録を読めるようにします。

    1. メニューの 拡張機能 → Apps Script を開く
    2. 最初からある中身をすべて消して、下のボタンでコピーしたコードを貼り付ける
    3. 保存のマークを押す
    中身を見る
  3. 3

    ウェブアプリとして公開する

    1. 右上の デプロイ → 新しいデプロイ
    2. 歯車のマークから、種類を ウェブアプリ に
    3. 次のユーザーとして実行：自分／アクセスできるユーザー：全員
    4. デプロイ を押し、権限の確認が出たら自分のアカウントで許可する

    「Google はこのアプリを確認していません」と出たら、「詳細」→「（安全ではないページ）に移動」で進めます。あなた自身が作ったコードなので心配はいりません。表示される /exec で終わるURLを控えておきます。

  4. 4

    アプリを発行する

    シートを開き直すと、メニューに フィジカルノート が出ます。フィジカルノート → アプリとつなぐ を押すと合言葉が作られ、このページの発行フォームが開きます。

記録は、好きな方法で。

アプリは見るための場所。記録はシートに入れば、どんな方法でもかまいません。

シートに直接書く

スマホの Google スプレッドシート アプリから、1行に1件ずつ。日付・食事区分・kcal・P/F/C を書くだけです。書き方はシートの「使い方」タブにあります。

AIに話しかけて書いてもらう

Gemini（無料版でも、設定のカスタマイズで Google Workspace をつなぐと書き込めます）や ChatGPT など、Googleドライブにつなげられる AI に「昼に鶏むね肉の定食を食べた」と話すだけ。最初に下の文を渡しておくと、決まった形で書き込んでくれます。

あなたは私の記録係です。Googleドライブの「フィジカルノート」というスプレッドシートに、私の食事・体重・トレーニングを書き込んでください。

・1件を1行で、各タブの最後の行の下に追加する。1行目の見出しと列の順番は変えない
・食事タブ：B 日付（YYYY-MM-DD）、D 食事区分（朝食／昼食／夕食／間食 など）、E 内容・量、F kcal、G P g、H F g、I C g、J 根拠・メモ、K 確定状態（確定／推定）
・体重タブ：B 日付、C 朝夜（朝／夜）、D 体重 kg
・トレーニングタブ：B 日付、C 区分（トレーニング／オフ）、D 部位、E 時間 分、M セット数、N セット内訳
・栄養がわからないときは、一般的な値やお店の公式の栄養情報から推定し、確定状態を「推定」にして根拠をJ列に書く
・取り消すときは行を消さず、有効の列に FALSE と書く
・書き込んだら、書いた内容を読み返して私に伝える

よくある質問

お金はかかりますか？

かかりません。Googleスプレッドシート、Apps Script、このアプリはすべて無料で使えます。

iPhoneでもAndroidでも使えますか？

どちらでも使えます。ブラウザで開いてホーム画面に追加すると、アプリのように使えます。パソコンのブラウザでも見られます。

「Google はこのアプリを確認していません」と出ました。

自分で貼り付けたコードを初めて動かすときに必ず出る画面です。「詳細」→「（安全ではないページ）に移動」→「許可」で進めてください。コードはシートを読むだけで、書き換えや外への送信はしません。中身は「中身を見る」から確認できます。

合言葉やリンクを人に知られたら？

シートのメニュー「フィジカルノート → 合言葉を作り直す」で新しい合言葉にできます。古いリンクは使えなくなるので、新しい接続リンクでアプリを開き直してください。

コードを直したら、アプリに反映されません。

Apps Script で デプロイ → デプロイを管理 → 鉛筆（編集）→ バージョン：新バージョン → デプロイ にすると、URLを変えずに反映できます。「新しいデプロイ」にするとURLが変わるので、もう一度発行が必要です。

年が変わったらどうなりますか？

同じシートに書き続けられます。アプリは見ている年の記録を読み込みます。

記録がアプリに出ません。

日付が日付として入っているか（例：2026-10-26）、見出しの行や列の順番が変わっていないか、「有効」に FALSE と書いていないかを確かめてください。アプリは下に引っ張ると読み込み直せます。
